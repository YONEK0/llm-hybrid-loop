> 版本：V6-PRE，2026-09-21
> 状态：规划文档（结论槽待填）。前置：`TRAINING_PLAN_V5_HYBRID_LOOPUS.md`（现行训练方案）、

## 一、定位声明

LoopUS（arXiv:2605.11011）证明了标准 Transformer 可后训练循环化（3B token 全参）。
我们的差异化空间来自三件论文没有的东西：

1. **混合架构**（3:1 DeltaNet + full attention）——论文只做标准 Transformer；
2. **机制级测量**——范数膨胀、平台区、接缝相位规则，全部是我们首测；
3. **昇腾栈**——循环深度 × 国产 NPU 训练模板，预判为空白（启动前须专项检索确认）。

**"超过"的可证伪定义**（对齐论文基准）：

| 指标 | 论文基准 | 我们的目标线 |
|---|---|---|
| 同模型同基准增益 | Qwen3-4B +1.8pp 平均（ARC-C +3.6） | 同基准 ≥ +2.5pp，**或**同增益下 token 预算 ≤ 1/10 |
| 深度外推 | b=100 稳定 | b=100 稳定 **且外推斜率更平**（范数膨胀率更低） |
| 早退 Pareto | 平均深度 3.39/8 质量不掉 | 同质量下平均深度更低（混合平台区假说） |
| 训练成本 | 3B token 全参 | 明确测出混合架构达到同等循环稳定性的真实 token 需求 |

## 二、壁垒候选与验证实验

### 壁垒 1：hybrid 原生循环方法学（最硬核，算法壁垒）

依据（已有 E1 证据）：S1a 平台区（hybrid CE 波动 0.65 vs 标准模型 3.27）、接缝相位规则
（旋转候选 L9-20 落败）、范数膨胀机制（冻结态每轮 +30~70%，训练后压至 +10%）。

| 实验 | 内容 | 成本 | 判定 |
|---|---|---|---|
| E-A3 | **相位门控 vs 块门控**：A3（仅 full-attention 层后放门，约 2 枚）vs A2（块边界单门），同数据同预算 5M | 本机 8h×2 | A3 的 CE(d)/范数膨胀/A_bar 效率任一显著优于 A2 → 差异化门控成立；全劣 → 论文式块门是 hybrid 最优，如实记录 |
| E-NORM | **范数阻尼损失**：在 A2 基础上加 `λ·max(0, ‖h_new‖−‖h_old‖−ε)` 项（λ 从 0.1 起） | 本机 8h×2 | 同预算下外推斜率（d1→d32 膨胀率）比纯 A2 更低，或同稳定度下收敛更快 → 机制级改进成立 |
| E-SEL | **切分规则对照**：LoopUS 相似度分段法 vs 我们的"平台+接缝"规则，各选块同训 | 本机 16h | 我们规则选出的块在同预算下 CE(d) 更优 → 切分方法学壁垒成立 |

> E-A3 结论：待填
> E-NORM 结论：待填
> E-SEL 结论：待填

### 壁垒 2：混合架构预适配假说（成本壁垒，潜在量级差异）

假说：3:1 混合架构训练后的中层平台区使模型天然接近循环不动点，** retrofit 成本比标准
架构低 1–2 个数量级**。若成立，LoopUS 的 3B token 是标准架构的价格，混合架构按比例大幅
折减——这是论文级声明。

| 实验 | 内容 | 成本 | 判定 |
|---|---|---|---|
| E-STD | **标准架构对照**：Qwen3-1.7B（已在缓存）用完全相同的 gate-only 配方跑 5M token，同协议测 CE(d)/范数/深度外推 | 本机 ~6h | 同预算下标准架构无法达到 hybrid 的稳定度（外推 FLAT 且 d≤32）→ 假说获 E2 级支持；两者相当 → 假说否证，如实记录 |
| E-SCALE | 预算阶梯：hybrid 在 {1M, 2.5M, 5M} token 处的稳定度曲线（已有 1M/2.56M/5M 三个点，补齐即可） | 已有大部分 | 测出"混合架构达到 FLAT 的最小 token 数"，与论文标准架构 3B 形成成本对照 |

> E-STD 结论：待填
> E-SCALE 结论：待填

### 壁垒 3：昇腾栈首发（生态壁垒）

 MindSpeed-LLM（主）/MindFormers（次）的 hybrid+loop 训练模板 + 27B 循环化模型。
前置检索（**必做，错误六教训**）：关键词须覆盖 `hybrid + looped/recurrent depth +
linear attention + Ascend/NPU/MindSpeed` 组合，确认空白后再投入。
执行载体：`torch_npu` 数值立栈（1–3 天）→ AI 辅助迁移至 MindSpeed-LLM →
等价性验收（同块 S1a 对表、CE(d) 对齐 CUDA 参考、深度 32 FLAT 复现、A_bar 形态一致）。

> 检索结论：待填
> 移植结论：待填

### 壁垒 4：长上下文 × 循环的部署组合（效果/部署壁垒）

混合架构仅 1/4 层为 full-attention，循环每加深一轮，KV 重算/缓存只涉及 16 层（27B）——
**唯一"深度计算增加而 KV 成本不爆炸"的组合**；论文在标准 Transformer 上的 B 倍缓存结论
在长上下文下不经济。验证：ctx 4K/16K 下 d=1 vs d=4 的吞吐/KV 显存实测（服务器阶段）。

> 结论：待填（服务器阶段）

## 三、执行序与依赖

```
[现在] L0 5M 跑完（进行中，step 1000/1953 暂停→续）
   ├→ 台阶1: lm-eval 基线 + 早退 Pareto（V5 已列）
   ├→ E-A3 / E-NORM（本机各 8h，可与 L1 数据共用）
   ├→ E-STD（本机 6h，1.7B 标准架构对照）
   └→ 壁垒3 检索（零 GPU）
[台阶2] 本机 LoRA + 官方超参（V5 台阶2）
   └→ E-SEL / E-SCALE 补齐
[服务器] 台阶2.5（4B 全参验管线）→ 27B LoRA-first → 壁垒3 移植 + 壁垒4 实测
```

依赖关系：壁垒 1 的三个实验不依赖服务器；壁垒 2 的 E-STD 本机即可；壁垒 3/4 依赖服务器
阶段。**任何一条壁垒独立成立，都构成"超过论文"的证据点**；全部失败则退回忠实复现路线
（壁垒 3 生态价值仍存）。

## 四、证据纪律（继承 V5）

- 每个实验独立目录、独立 JSON、不覆盖；对照先行（同数据/同预算/同评分）；
- benchmark 类结论 n≥1000 或标注方向性；深度外推与范数曲线必须落盘；
- 启动壁垒 3 前必须完成专项文献检索（含工程关键词），检索记录落盘；
- 所有"超过论文"的声明必须指明对照条件与 E 等级（E0–E3）。
